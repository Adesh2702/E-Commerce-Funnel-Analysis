## 🎨 Portfolio Description (for personal website/portfolio page)

**E-Commerce Funnel Analysis: Root Cause of Conversion Drop**

When an e-commerce platform's conversion rate declines but traffic stays flat, the problem isn't visibility — it's friction somewhere in the purchase journey. This project traces 50,000 simulated sessions through the full funnel (page view → purchase), using SQL to segment behavior and Python to visualize it, pinpointing that most lost revenue was concentrated in a single transition: Add to Cart → Checkout, driven by mobile UX and payment-method friction. The result is a dashboard stakeholders can filter themselves, backed by a report that ties every finding to a specific, actionable fix.

**Tools:** SQL · Python · Tableau  **Focus:** Root cause analysis, funnel diagnostics, executive dashboarding

## 📢 LinkedIn Project Post

🛒 **New Project: Why do 93% of website visitors leave without buying?**

I just wrapped up an end-to-end data analytics project diagnosing conversion drop-off across a simulated e-commerce funnel of 50,000 sessions — and the root cause wasn't what I expected going in.

📉 The funnel showed a healthy 62% of visitors viewing a product... but only 7.3% completing a purchase.

💡 Key takeaway: the "leak" wasn't a traffic or marketing problem — it was a product/checkout-experience problem, and fixing it didn't require a single extra rupee of ad spend.
